# LLM Prompt Engineering Dashboard

An interactive web application built with Python and Streamlit that demonstrates different prompt engineering techniques and generates AI responses using the Groq API.

## Project Overview

The LLM Prompt Engineering Dashboard allows users to experiment with different prompting techniques and understand how prompts influence the responses generated by a Large Language Model (LLM).

The application combines a Streamlit user interface, reusable prompt templates, and the Groq API to generate responses based on user input.

## Features

- Interactive dashboard built using Streamlit.
- Zero-Shot Prompting to generate responses without examples.
- Few-Shot Prompting to guide the model using examples.
- Role-Based Prompting to influence responses by assigning a specific role.
- Structured prompts for clear and relevant answers.
- AI response generation using the Groq API.
- Reusable prompt templates managed through a separate Python module.
- Secure API key configuration using environment variables or Streamlit secrets.

### File Descriptions

- `app.py` – Main Streamlit application and user interface.
- `llm.py` – Handles communication with the Groq API and generates AI responses.
- `prompt_templates.py` – Defines reusable prompt templates.
- `requirements.txt` – Lists the required Python dependencies.
- `.env` – Stores local environment variables.
- `.streamlit/secrets.toml` – Stores Streamlit secrets when using that configuration method.
- `README.md` – Contains project documentation.

Note: `.env` and `secrets.toml` are alternative ways to configure the API key. You do not need to use both.

## Installation and Setup

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd llm
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with your actual GitHub repository URL.

### 2. Install Dependencies

```bash
python -m pip install -r requirements.txt
```

If the Groq SDK is not included in `requirements.txt`, install it using:

```bash
python -m pip install groq
```

If you use a `.env` file, install:

```bash
python -m pip install python-dotenv
```

### 3. Configure the Groq API Key

Create an API key through the [Groq Console](https://console.groq.com/keys).

#### Option A: Using a `.env` File

Create a `.env` file in the project directory:

```env
GROQ_API_KEY=your_actual_groq_api_key
```

Load it in Python using `python-dotenv`:

```python
import os
from dotenv import load_dotenv

load_dotenv()

api_key = os.getenv("GROQ_API_KEY")
```

#### Option B: Using Streamlit Secrets

Create `.streamlit/secrets.toml`:

```toml
GROQ_API_KEY = "your_actual_groq_api_key"
```

Read the key in your Streamlit application using:

```python
import streamlit as st

api_key = st.secrets["GROQ_API_KEY"]
```

Use the configuration method expected by your application code.

Security: Never upload your actual API key, `.env` file, or private secrets to GitHub. Add them to `.gitignore`.

Example `.gitignore`:

```gitignore
.env
.streamlit/secrets.toml
__pycache__/
*.pyc
```

### 4. Run the Application

From the project directory, execute:

```bash
python -m streamlit run app.py
```

Open the local URL displayed in the terminal, usually:

`http://localhost:8501`

## Application Workflow

1. The user opens the Streamlit dashboard.
2. The user enters a prompt and selects a prompting technique.
3. The application uses `prompt_templates.py` to structure the prompt.
4. The formatted prompt is passed to the response-generation function in `llm.py`.
5. The Groq API processes the request using the configured language model.
6. The generated response is displayed in the Streamlit interface.
